# 北航生医工/医工两院导师信息索引

> 本项目面向北京航空航天大学生物与医学工程学院、医学科学与工程学院相关导师与师资信息查询，优先整理学院官网、北航教师个人主页等公开可核验来源。

[在线系统](https://donaldjoker2025-arch.github.io/my-buaa-app/)

## 核心功能

* 工作台式 UI：首屏展示数据概览、导师/师资记录数、培养方向索引数、公开邮箱记录和兼职导师标注。
* 多维检索：支持按导师姓名、学院、培养方向、邮箱、关键词搜索。
* 分类筛选：支持按学院和公开培养方向筛选，适合先缩小择导范围再逐条核验。
* 导师信息栏：补充公开方向数量、联系方式状态、硕士/博士生导师标签、资料完整度、学生选择线索和联系入口。
* 完整方向覆盖：生物力学、生物医学材料、细胞与组织工程等方向均已纳入，不再按个人偏好筛除。
* 来源跳转：优先提供教师个人主页或学院教师详情页；没有精确个人页时不再使用泛化跳转。
* 招生与科研线索：补充 2026 博士招生资格名单线索，以及教师主页中可公开核验的科研方向、论文或基金摘要。
* 普适建议：保留通用联系导师和信息核验建议，不绑定特定奖项或个人背景。

## 数据来源

* 北京航空航天大学生物与医学工程学院：硕士研究生培养方向设置及指导教师对照表。
* 北京航空航天大学生物与医学工程学院：师资队伍页面。
* 北京航空航天大学生物与医学工程学院：医工交叉学科群 2026 年博士生招生资格导师名单。
* 北京航空航天大学医学科学与工程学院：人员列表。
* 北京航空航天大学医学科学与工程学院：师资人员详细索引。
* 北京航空航天大学医学科学与工程学院：医工交叉学科群 2026 年博士研究生招生工作方案。

## 数据更新

运行 `npm run generate:details` 可从公开官网页面和本地缓存重新生成 `src/supervisorDetails.js`，用于补充个人主页、公开邮箱、硕/博导标签、科研摘要和招生线索。

## 说明

学院官网页面可能迁移，同名教师、跨学院任职、兼职导师等情况也会造成旧资料失效。页面中未由公开来源直接确认的信息不再展示，最终请以学院官网、北航教师个人主页和当年招生通知为准。
